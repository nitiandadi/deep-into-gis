# 空间索引

1. 空间索引本质：：按照一定的空间规则，对空间数据进行组织或划分，建立的一种能够快速减少搜索范围的数据结构。
2. 空间索引应用场景：海量空间数据里快速找到想要的数据，避免全量便利。
3. 常用的空间索引：四叉树，八叉树，网格索引。

名词解释：

- 四叉树空间索引:在二维空间递归的划分为四个子空间。
- 八叉树四叉树空间索引:在三维空间里把区域递归的划分为把个子空间。
- 规则网格索引：使用规则网格划分二维空间。俗称格子化。
- Rtree:空间上相近的要素分组，用外接矩形逐层组织成树。（还需要加深理解）
