# GIS 行业图谱

哪些行业会招聘 GIS 开发者？它们解决的问题、使用的技术和要求的能力有什么不同？这个专题从招聘需求、项目场景和个人观察出发，寻找 GIS 跨行业变化中的共同底座。

3. 如何从招聘信息判断岗位真正需要的技术方向

## 写作原则

- 不只罗列行业名称，要说明 GIS 在其中解决的核心问题。
- 不只罗列技术栈，要解释技术选择与业务约束的关系。
- 区分招聘描述、项目实际需求和长期能力建设。
- 寻找行业差异，也提炼可以跨行业迁移的共性能力。
